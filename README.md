# Phygital Machines

Учебная среда программирования гоночных машинок для образовательного центра Smart Bolashaq.

Ученик пишет на Python в редакторе на ПК, код уходит по кабелю или Wi-Fi на Raspberry Pi Zero 2 W внутри машинки и выполняется там в изолированной песочнице — не мешая пилоту рулить и не ломая видеопоток.

Философия: **прячем физику проводов, показываем мышление.** Протокол ленты WS2812 и несущая 38 кГц ученику не нужны — это шум. А углы, паузы и последовательности он задаёт сам и отвечает за них.
Философия среды: **IDE подсказывает, ЧТО есть и ПОЧЕМУ ошибка — но не пишет код за ученика.**

## Возможности (v1.15)

- **Три вкладки: «Домой», «Основы Python», «Машинка».** Стартовый экран «Домой» показывает две дороги с прогрессом и состоянием связи; инструкция открывается по «?» в шапке; версия видна в углу. У вкладки «Машинка» — точка связи (серая/зелёная), слева карточка состояния с кнопкой «Подключить», «Свободный режим» (бывший «Бортовой компьютер») и список уроков с галочками «пройдено». Пока машинка не подключена — три шага подключения вместо редактора (или «Писать код без машинки»), в уроке — жёлтая плашка над редактором.
- **Единая панель «Мои программы»** (`renderer/projects.js`) в обоих редакторах — программы из песочницы Python и для машинки лежат в одной папке; Ctrl+Enter / Esc / Ctrl+S работают одинаково. Подсказки первого запуска (`renderer/tips.js`) показываются один раз, сбрасываются в настройках. Короткие уведомления — тостами. Масштаб интерфейса: Ctrl + / − / 0.
- **Вкладка «Основы Python»** — курс «Основы Python» из 10 модулей с песочницей. Код исполняется настоящим CPython (Pyodide, WebAssembly) прямо в программе: ничего ставить на компьютер не нужно, работает офлайн, код ученика в песочнице без доступа к системе. Есть `input()` как в терминале, кнопка «Стоп» прерывает даже `while True`, ошибки объясняются по-человечески на двух языках. Черепашка (`import turtle`) рисует на холсте справа от редактора; `open()` работает с файлами в папке ученика. У каждого задания — подсказка, ответ и автопроверка на тестах (26 из 30 заданий), прогресс сохраняется. Тексты курса — в `renderer/course-data.js` (RU+KK), исполнитель — `renderer/py-worker.js`, проверка — `renderer/course.js`.
- **Бортовой компьютер**: редактор Python с живым линтом, мягким автодополнением (и авто-подсказкой с третьего символа), подсказками по наведению и консолью машинки.
- **Карта пинов** реальной малинки на 40 контактов: видно, что занято пилотом, что системой, а что свободно ученику. Сворачивается переключателем.
- **Понятные ошибки** на русском и казахском: вместо трассировки Python — объяснение и «ты имел в виду?» при опечатке в имени команды.
- **Программы ученика** — обычные файлы `.py` в видимой папке (по умолчанию «Документы\Phygital Machines»). Их видно в проводнике, можно скопировать на флешку или отдать учителю. Имя программы и список — в шапке редактора, сохранение по кнопке или Ctrl+S, метка «•» показывает несохранённые правки. Удаление — в корзину.
- **Уроки с машинкой** (v1.15) — интерактивный курс из 8 уроков в том же формате, что и «Основы Python»: цель, теория, примеры, 24 задания с автопроверкой (🟢🟡🔴), RU+KK. Код ученика исполняется на **виртуальной машинке** прямо в IDE (`renderer/py-worker.js`, модуль `_sbcar`): панель рядом с редактором показывает ленту из 9 диодов, ИК-пушку, серво и пины, а кнопки 1–3 и «попадание» нажимаются мышью, пока программа работает. «Проверить» прогоняет программу по сценарию (нажатия кнопок, попадания, уровни на пинах в виртуальном времени — секунды не ждём) и судья на Python (поле `judge` задания) смотрит журнал ленты, серво, пинов и выстрелов. Кнопка «На машинку» отправляет тот же код на настоящую, когда она подключена. Тексты и судьи — в `renderer/car-course-data.js`, панель — `renderer/py-car.js`, оба курса собирает одна фабрика `sbMakeCourse` (`renderer/course.js`). Машинка для уроков не нужна: вкладка открывается сразу на курсе, свободный режим — рядом в списке слева.
- **Изменяемая высота консоли**: разделитель перетаскивается мышью, высота запоминается.
- **Настройки (⚙)**: светлая/тёмная тема, масштаб, сброс подсказок, автообновление; адрес машинки — в «Дополнительно».
- **Автообновление**: программа замечает новую версию в Releases и предлагает обновиться (выпуск = поднять `version` в `package.json`).
- **Два языка интерфейса**: русский и казахский.

## API машинки

Плоский, без импортов — как `digitalWrite(9, HIGH)` в Arduino: посмотрел на строку и сразу понял, какой пин и что делает.

| команда | что делает |
|---|---|
| `pin(n, HIGH/LOW)` | подать или снять 3.3В на пине n |
| `servo(n, deg)` | серво на пине n → угол 0–180. Паузу ставит сам ученик |
| `read(n)` | уровень на пине n: 1 или 0 |
| `strip(i, r, g, b)` | цвет i-го диода встроенной ленты в буфере (0–8) |
| `show()` | вывести буфер на ленту |
| `fire()` | ИК-выстрел встроенной пушкой (не чаще раза в 0.5 с) |
| `on_hit(func)` | вызвать func, когда в машинку попали |
| `on_button(n, func)` | вызвать func, когда пилот нажал кнопку ловушки n (1–3) |
| `wait(sec)` | пауза в секундах |
| `forever()` | держать программу живой и ждать события |
| `print(text)` | вывести текст в консоль IDE |

Три кнопки ловушек — **программируемые слоты**, а не готовые ловушки. Машинка только сообщает о нажатии; что произойдёт, решает код ученика.

### Карта пинов (BCM)

| пин | занят | доступ ученику |
|---|---|---|
| 13 | мотор (ESC) | нет, рулит пилот |
| 18 | руль (серво) | нет, рулит пилот |
| 10 | лента WS2812 по SPI | через `strip()` / `show()` |
| 25 | ИК-приёмник | через `on_hit()` |
| 12 | ИК-передатчик | через `fire()` |
| 17, 22, 23, 24, 27 | свободны | да |

У малинки нет ардуиновского деления на «ШИМ» и «не-ШИМ»: pigpio выдаёт точные импульсы на любом пине, поэтому свободные пины взаимозаменяемы.

Сервер-судья на машинке проверяет код **до** запуска и не даст тронуть занятые пины — ни явно, ни вычисленным номером.

## Как получить установщик

Собирается автоматически в GitHub Actions при загрузке в ветку `main`. Через несколько минут файл `PhygitalMachines-Setup-<версия>.exe` появится в разделе **Releases**. Чтобы выпустить обновление, поднимите `version` в `package.json` — установленные программы предложат обновиться сами.

## Облачные материалы

С v1.15 уроки с машинкой встроены в программу (`renderer/car-course-data.js`) и не требуют интернета. Загрузка PDF-уроков и мини-тестов из облака больше не используется; папка `cloud-repo-example` оставлена как образец на будущее.

## Связь с машинкой

- **По кабелю** — USB-гаджет NCM на малинке, адрес `10.55.0.1`. Работает без Wi-Fi, ничего настраивать не нужно.
- **По Wi-Fi** — машинка поднимает точку `Car_<ID>_WiFi` по команде с телефона пилота, адрес `10.42.0.1`.

Адрес машинки задаётся в настройках.

## Разработка

```bash
npm install          # зависимости
npm start            # запуск
npm run dist         # сборка установщика (на Windows)
```

Структура:

- `main.js` — главный процесс Electron: настройки, программы учеников, связь с машинкой по TCP, автообновление
- `preload.js` — мост между главным процессом и интерфейсом
- `renderer/app.js`, `renderer/home.js` — вкладки, «Домой», язык, тема, масштаб
- `renderer/car.js` — редактор машинки (свободный режим), подсказки, линт, карта пинов
- `renderer/lessons.js` — вкладка «Машинка»: свободный режим + курс «Уроки с машинкой»
- `renderer/car-course-data.js` — уроки с машинкой: тексты (RU+KK), примеры, задания, судьи на Python
- `renderer/course.js`, `renderer/course-data.js` — фабрика курсов и курс «Основы Python»
- `renderer/py.js`, `renderer/py-worker.js` — рабочая панель Python и исполнитель (Pyodide): песочница, черепашка, виртуальная машинка, судья
- `renderer/py-car.js`, `renderer/py-turtle.js` — панель виртуальной машинки и холст черепашки
- `renderer/projects.js`, `renderer/tips.js` — «Мои программы» и подсказки первого запуска
- `renderer/i18n.js` — русский и казахский
- `.github/workflows/build.yml` — автосборка установщика

Сторона машинки (не в этом репозитории): `main.py` — пилот, `bortovoy_server.py` — сервер-судья песочницы, `runner.py` — изолированный процесс ученика, `zhelezo.py` — единый слой железа.
