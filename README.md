# Smart Bolashaq IDE

Учебная среда программирования Arduino для образовательного центра Smart Bolashaq.

## Возможности (v1.1)

- **Компилятор Arduino** на основе официального arduino-cli: проверка кода и загрузка на плату (Uno, Nano, Mega) одной кнопкой.
- **Защищённый шаблон кода**: обязательные строки проекта отмечены знаком 🔒 — их невозможно изменить или удалить. Ученик может только дополнять код в разрешённых местах.
- **Интерактивные уроки**: теория и задание слева, редактор с шаблоном урока справа, автопроверка условий («Задание выполнено ✓»). Уроки создаются конструктором в панели админа и хранятся в облаке.
- **PDF-материалы** из облака (GitHub), офлайн-кэш после первого открытия.
- **Монитор порта** с отправкой команд плате (Serial).
- **Проекты учеников**: автосохранение и именованные проекты.
- **Режим администратора** по паролю (по умолчанию `smartbolashaq` — смените!): настройки, библиотеки, конструктор уроков.
- **Библиотеки**: Servo, Adafruit NeoPixel, FastLED, IRremote, NewPing, DHT встроены в установщик; новые ставятся из облака (zip в репозитории + раздел `libraries` в manifest.json).
- **Автообновление**: программа сама замечает новую версию в Releases и предлагает обновиться (выпуск = поднять `version` в package.json).
- **Два языка интерфейса**: русский и казахский.
- **Работа без интернета**: ядро AVR и библиотеки встроены в установщик.

## Как получить установщик

Установщик собирается автоматически в GitHub Actions. Загрузите этот проект в свой GitHub-репозиторий — через несколько минут готовый файл `SmartBolashaqIDE-Setup-1.0.0.exe` появится в разделе **Releases**. Подробная пошаговая инструкция — в файле `Инструкция-по-GitHub.md`.

## Настройка облачных материалов

1. Создайте на GitHub публичный репозиторий, например `smartbolashaq-materials`.
2. Загрузите туда PDF-файлы и файл `manifest.json` (образец — в папке `cloud-repo-example`).
3. В приложении откройте «Настройки» и укажите адрес:
   `https://raw.githubusercontent.com/ВАШ_ЛОГИН/smartbolashaq-materials/main/`

Список материалов можно менять в любой момент — приложение подхватит изменения без переустановки.

## Как изменить обязательный шаблон кода

Шаблон описан в файле `resources/template.json`. Каждая строка имеет флаг `locked`:

```json
{ "text": "void setup() {", "locked": true },
{ "text": "  // сюда ученик пишет код", "locked": false }
```

`locked: true` — строка защищена. После изменения шаблона загрузите файлы в GitHub заново — соберётся новый установщик.

Шаблон можно также обновлять **через облако без переустановки**: добавьте поле `template` в `manifest.json` (см. образец) — оно имеет приоритет над встроенным шаблоном.

## Разработка

```bash
npm install          # зависимости
npm test             # тесты защиты строк
npm start            # запуск (нужен arduino-cli в build-resources/arduino-cli)
npm run dist         # сборка установщика (на Windows)
```

Структура:

- `main.js` — главный процесс Electron: запуск arduino-cli, PDF, настройки
- `renderer/` — интерфейс (редактор, материалы, настройки)
- `renderer/editor.js` — механизм защищённых строк (CodeMirror)
- `resources/template.json` — обязательный шаблон кода
- `.github/workflows/build.yml` — автосборка установщика
